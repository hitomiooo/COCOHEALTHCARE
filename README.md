# COCOHEALTHCARE

ココちゃんたちの健康管理アプリです。

## LINE通知の準備

健康記録ごとに通知する・しないを選び、共有相手1人へ編集可能な文章を送れます。
LINE公式の無料共有画面を使用するため、LINE公式アカウント、アクセストークン、Firebase Functionsは不要です。
「LINEで通知する」を選んで記録を保存するとLINEが開くので、共有相手を選んで送信します。

病院情報はトロッコ動物病院の公式診療カレンダー（http://torocco-vet.com/schedule/）から取得します。
カレンダーが画像で掲載されているため、確認済み画像のハッシュと照合します。画像が変更された場合は古い日程を使わず、画面に「公式サイトを確認」と表示します。
取得処理は無料のGoogle Apps Scriptを使用します。
